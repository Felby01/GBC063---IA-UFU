# Simulação de Corrida de Cavalos com Inteligência Artificial


> Sobre o projeto

Este projeto tem como objetivo desenvolver um agente de Inteligência Artificial capaz de aprender a prever os resultados de uma corrida de cavalos.

O agente deverá analisar os cavalos e tomar decisões sobre suas posições de chegada, buscando aprender por meio de um sistema de recompensas.


> Objetivo

Explorar o aprendizado por reforço em um ambiente de corrida de cavalos, utilizando recompensas para incentivar o aprendizado do agente.


> Funcionamento

- Ambiente: uma corrida de cavalos simulada.
- Agente: uma Inteligência Artificial que aprende a tomar decisões.
- Objetivo do agente: prever os resultados da corrida.
- Recompensas: utilizadas para orientar o aprendizado do agente de acordo com os resultados obtidos.
